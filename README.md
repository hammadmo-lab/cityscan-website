# City Scan Radiology Center Website

Static website for City Scan Radiology Center, built with React, Vite, and Tailwind CSS.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## Cloudflare Pages

Use these settings:

```txt
Framework preset: Vite
Build command: npm run build
Build output directory: dist
```
